# Navier-Stokes Synthetic Dataset Description (2D Compressible Flow)

This dataset contains a synthetic 2D compressible flow field representing an isentropic vortex superimposed on a uniform mean flow. The flow is periodic in both x and y directions.

## Variable Definitions

- **velocity_u (u)**: x‑component of velocity, units of m/s (non‑dimensional). Mean flow = 1.0, vortex perturbation added.
- **velocity_v (v)**: y‑component of velocity, units of m/s (non‑dimensional). Mean flow = 0.0, vortex perturbation added.
- **pressure (p)**: pressure field, units of Pa (non‑dimensional). Computed from isentropic relation p = rho^γ.
- **density (rho)**: density field, units of kg/m³ (non‑dimensional). Base density = 1.0 with vortex-induced variations.
- **temperature (T)**: temperature field, units of K (non‑dimensional). Base temperature = 1.0 with vortex-induced variations.
- **coordinates**: (x, y) positions in meters (non‑dimensional, domain [0, 2π] × [0, 2π]).

## Data Generating Process

The flow is an isentropic vortex (a exact solution of the compressible Euler equations) superimposed on a uniform freestream (u_inf = 1.0, v_inf = 0.0). Parameters:
- Vortex strength ε = 0.5
- Vortex core radius = 0.2 (in nondimensional units)
- Specific heat ratio γ = 1.4
- Reference temperature T0 = 1.0, reference density ρ0 = 1.0

Perturbations are derived from a streamfunction φ such that:
- δu = -∂φ/∂y, δv = ∂φ/∂x
- φ = ε * exp(-r²/(2*r0²)) / (2π), where r² = (x - L/2)² + (y - L/2)²

Temperature and density perturbations follow from isentropic relations:
- T/T0 = 1 - (γ-1)ε²/(2γ) * exp(-r²/r0²)
- ρ/ρ0 = (T/T0)^(1/(γ-1))
- p = ρ^γ

The domain size is L = 2π in each direction, discretized with N = 64 grid points per dimension (uniform grid). No noise is added; the field is deterministic.

## Known Properties and Caveats

- The flow satisfies the compressible Euler equations (inviscid) exactly.
- Entropy is constant throughout the field (isentropic vortex).
- The dataset is ideal for testing compressible Navier‑Stokes solvers, vortex propagation, and shock‑capturing methods (though no shocks present).
- No temporal evolution is included; only a single snapshot is provided.
